## ✅ Тестові сценарії

### 1. ❌ Cannot increment quantity beyond available stock on product page

**Тег**: `@critical @stock`  
**Опис**: Перевіряє, що кількість не може перевищити наявний stock на сторінці товару  
**Кроки**:

- Перейти на сторінку деталей товару
- Перевірити доступний stock
- Спробувати збільшити кількість понад limit
- Верифікація: кількість не перевищує stock і UI залишається функціональним

---

### 2. ❌ Add to cart button is disabled when out of stock

**Тег**: `@critical @stock`  
**Опис**: Перевіряє, що кнопка "Add to Cart" вимкнена для товарів без stock  
**Кроки**:

- Перейти на сторінку товару з низьким або нульовим stock
- Перевірити, що кнопка вимкнена або показується помилка
- Верифікація: з'являється повідомлення про відсутність stock

---

### 3. ❌ Can add product with exact stock quantity on product page

**Тег**: `@critical @stock`  
**Опис**: Користувач може додати товар з точною кількістю доступного stock  
**Кроки**:

- Перейти на сторінку товару
- Встановити кількість = доступному stock
- Клікнути "Add to Cart"
- Верифікація: товар успішно додався у кошик

---

### 4. ❌ Cannot update cart quantity beyond available stock

**Тег**: `@stock @cart`  
**Опис**: У кошику неможливо збільшити кількість понад доступний stock  
**Кроки**:

- Авторизуватися
- Додати товар у кошик
- Перейти у кошик
- Спробувати збільшити кількість понад limit
- Верифікація: кількість не перевищує stock, показується помилка

---

### 5. ❌ Update cart to maximum available quantity succeeds

**Тег**: `@stock @cart`  
**Опис**: Оновлення кількості до максимуму успішне  
**Кроки**:

- Авторизуватися
- Додати товар у кошик
- Перейти у кошик
- Встановити кількість = максимуму
- Верифікація: оновлення успішне

---

### 6. ❌ Error message is displayed when exceeding stock

**Тег**: `@regression @stock`  
**Опис**: Отримується помилка при спробі перевищити stock  
**Кроки**:

- Перейти на сторінку товару
- Спробувати додати понад доступну кількість
- Верифікація: з'являється помилка про недостатність stock

---

### 7. ❌ UI remains functional after stock validation error

**Тег**: `@regression @stock`  
**Опис**: UI залишається функціональним після помилки валідації stock  
**Кроки**:

- Перейти на сторінку товару
- Спробувати перевищити stock
- Верифікація: можна навігувати, взаємодіяти з елементами, сторінка не ламається

## 🚀 Як запустити тести

### Попередні умови:

1. Встановити залежності:

   ```bash
   npm install
   ```

2. Запустити тестовий сервер:
   ```bash
   npm run docker:up
   # або запустити локально вашу application на http://localhost:3001
   ```

### Запуск тестів:

```bash
# Запустити всі stock validation тести
npm run test:run -- --grep "@stock-validation"

# Запустити лише critical тести
npm run test:run -- --grep "@critical @stock"

# Запустити з UI
npm run test:ui
```

### Перегляд результатів:

```bash
npm run report:html
```
